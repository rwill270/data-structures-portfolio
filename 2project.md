# How accurately can a previous-season's performance predict an NFL wide receiver's receiving yards in the following regular season?

### Background

This project examines whether previous-season production from NFL wide receivers can be used to predict an individual player's receiving yards in the following season. The project compares a simple previous-season-yards model with multiple linear regression and random forest regression to determine how accurately each approach predicts future receiving production. I selected Receiving yards as the main target because they provide a straightforward measure of a receiver's offensive production and can be compared across all players and seasons. Machine learning models have been used in the past to predict stats in the NFL but it is very important to use the correct variables in your predictions. Being able to estimate a player's future receiving production can provide useful information for sports analysts, fantasy football players, coaches, scouts, and other people interested in evaluating player performance.
